Custom rhythm editor

Enter note denominators separated by spaces. Use r8 for an eighth rest, 8. for dotted eighth, 8.. for double dotted, 16*2/3 for a triplet sixteenth, and ~ before a continuation of a tied note (e.g. 4 ~8). Use | for measure boundaries and a new line for another voice. Each voice must have the same total length, and each measure must be complete.

First draft • Repertoire-inspired rhythm studies, not verified score excerpts. Tapping evaluates note onsets, not sustained key duration.
